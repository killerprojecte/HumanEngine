# Native source-learning batch

The batch captures source model-read permission, projects trusted identifiers,
searches related memory, extracts candidates, reviews an explicit durable empty
result, repairs unsupported pronouns, reconciles against authorized targets,
and persists habits before memories through the actual domain writers.

Extraction cannot grant merge/supersede authority. Unknown references invalidate
one call without changing its position or budget. The source's one extra review
or repair request, eight-candidate policy and 4000 UTF-16 search slice are
preserved. JSON contracts retain pinned Zod codepoint lengths and JavaScript
whitespace/date behavior.

The source proposal wrapper checks current feature settings and source snapshots,
resolves attribution, validates pronouns, commits through MemoryService, then
runs public review and embedding index outside that writer transaction. The
learningowner package supplies concrete read/review/index adapters; no production
fallback adapter returns success without doing work.

Actual-source contract and multi-stage request fixtures complement real SQLite
persistence/recovery tests. Progress distinguishes applying intent, pending
outcome and saved/rejected/ignored counts, including failures after durable commit.
