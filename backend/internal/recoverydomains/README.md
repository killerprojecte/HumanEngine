# Native offline lifecycle owners

This package ports `memory/recovery/domain-ports.ts`, its actual Habit/Meme/Experience
lifecycle mutations, `memory/recovery/experience-trials.ts`, and the receipt mutation
rules used by `ExperienceTrials`. It is an offline maintenance owner, not a replacement
for the full live learning or image-analysis APIs.

`NewWithOptions` constructs the real domain schemas, rebuilds media concepts and
marks interrupted analyses. `NewTrialsWithOptions` does not construct schemas merely
by being instantiated. Both use an admitted `recovery.Maintenance`; `Verify` binds the
supplied transaction instead of acquiring the root maintenance lock again. `Options.Compare`
must be the deployment's pinned native locale comparator. There is no lexical fallback.
`Options.Now` permits source-compatible clock injection; its default is `time.Now`.

The implementation preserves source revocation multiplicity, qualification hashes,
sequence-wide removed-policy and expected-media state, source receipt evidence checks,
CAS checks, lazy trial storage, the source's existing 4096 receipt policy, and deletion
of files before media rows. No learning, new authority intent, global ACK, event
deduplication, or synthesized missing evidence is performed. The bare trial recovery
port has no service before-write hook; service-owned trial erasure raises reader 9 and
records the exact lifecycle mutation.

## Synthetic source comparisons

From the repository parent directory:

    HE_SOURCE_ROOT=humanengine-golang-recovered node --experimental-transform-types \
      he-stage39-domain-overlay/backend/scripts/recovery-domain-oracle.mjs
    HE_SOURCE_ROOT=humanengine-golang-recovered node --experimental-transform-types \
      he-stage39-domain-overlay/backend/scripts/recovery-trials-oracle.mjs

The checked-in fixtures were generated by the actual source owners with a fresh
synthetic temporary database. They include a comparison matrix captured from Node's
actual `localeCompare`, not a substitute alphabetical implementation. No live files
or network service is used. The Go tests consume these fixtures without starting Node.

Run the focused tests with the repository's required SQLite profile:

    go test -tags sqlite_fts5 ./internal/recoverydomains

Coverage includes constructor side effects, ordered domain transitions, source recall,
policy deletion superseding an earlier state, repeated media deletion, persisted trial
suspend/restart/erase, proof corruption despite intact receipt hashes, native transaction
loss, scope expiration/binding, and filesystem failures before SQL deletion.

At initial handoff both source generators and gofmt succeeded; Go compilation/tests
were deliberately delegated to the parent's serialized build window and are not yet
claimed as passed here.
