# Bounded administrative meme browsing

The administrative `GET /api/memes` response is now `{ items, total, page, pageSize }`, not an array. Deploy the generated client and server together and refresh already-open old clients. `page` starts at one, `pageSize` defaults to 24 and is capped at 96. Search and scope/status filters are applied in SQLite before counting and selecting a bounded page; only selected records are parsed in the application. The page is clamped after filtering or record removal. Ordering is newest insertion first with stable row identifiers; this is offset pagination, not a snapshot/cursor guarantee under concurrent insertions.

The browser offers 12, 24, 48 and 96 items per page, independent comfortable/compact card density and direct page navigation. Search is debounced and page/filter changes abort previous requests; generation checks prevent outdated responses from repainting the current page. No entire-catalog metadata request is needed to save or analyze an item: those preflight checks use `GET /api/memes/{id}`.

A viewport observer starts a bounded three-worker thumbnail queue with a 200px prefetch margin. `GET /api/memes/{id}/thumbnail` decodes only the first frame into a WebP at most 320 pixels per side. A 128-entry process-memory cache coalesces duplicate in-flight requests. Preview responses are authenticated and use `no-store`; browser object URLs are revoked when leaving the page or component. Full animated original media is fetched only when opening details, preserving the existing original bytes. Failures show an explicit preview error; original-media retry is read-only.

The interaction references MaiBot's separate page-size controls, bounded pagination and thumbnail loading states in `dashboard/src/routes/resource/emoji/EmojiBrowser.tsx` and `dashboard/src/components/emoji-thumbnail.tsx` at commit `062d45cf8bd4272ac57d7ec03fcf405e5a458211`. It does not copy MaiBot's implementation or claim identical behavior.

Focused automated coverage seeds 5,003 synthetic records and verifies bounded non-overlapping pages, combined filters before paging, literal search wildcards, Chinese search, empty/end-page clamping, single-item reads and scope counts. GIF and animated WebP tests verify single-frame thumbnails and unchanged original bytes. API coverage validates query bounds and thumbnail authentication. Browser QA is recorded separately; these automated checks alone are not visual acceptance or a large-scale throughput guarantee.
