## Broader design scope not implemented by these narrow experiments

- Slice 17 adds finite autonomous attributed summary candidates and exact-anchor declaration groupings, not destructive summary merging, recursive summary hierarchies, generalized episode synthesis or invented joint-event/causal narratives. Deterministic accessibility metadata remains distinct from this optional semantic layer.
- The original relation experiment covers qualified participation; slice 16 adds a finite versioned predicate/value registry and bounded one/two-hop discovery. Neither is an arbitrary ontology or unrestricted knowledge graph.
- Experience policies contain three fixed actions; only the explicit style preference has a narrow automatic activation route. Person/plan strategies still require management activation, not general reward-driven policy learning.
- Historical reads expose currently authorized retained versions, not a complete event log of every confirmation state at any past instant.
- The existing platform adapter has no actual edit-event input; synthetic explicit-edit tests do not add that platform capability.

These are explicit scope limits, not features claimed complete or merely awaiting an API key. The user has authorized the remaining finite implementation sequence; each next slice still has its own concrete contract and acceptance gate before publication.
