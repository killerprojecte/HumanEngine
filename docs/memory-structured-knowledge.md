# Structured knowledge (Slice 16)

This is a finite, versioned extension to attributed knowledge, not an unrestricted ontology or a truth engine. All three controls default OFF: `memoryKnowledgeEnabled` admits and maintains knowledge, `memoryKnowledgeAutoAdmissionEnabled` permits the documented low-risk admission rule, and `memoryKnowledgeAnswerEnabled` permits model-facing graph reads. Existing participation-graph controls do not enable this subsystem. Learning and model read/personalization controls continue to apply independently. Changing knowledge controls invalidates already issued graph tickets, including OFF→ON transitions; maintenance of revoked sources does not stop when features are OFF.

## Claims and admission

Registry v1 supports participates_in, prefers_topic, uses_tool, member_of, part_of, depends_on, and has_property. The latter has fixed properties version (text), count (nonnegative integer), duration (nonnegative number with seconds/minutes/hours), and enabled (boolean). Predicate/schema identity is persisted. New titles create distinct opaque entities: equal titles and verified identity links are not evidence that entities or assertions are identical.

Every edge retains polarity, modality, temporal scope, conditions, optional exact validity dates, complete AND proof groups with OR alternatives, source references, backing versions/epochs, and typed entity dependencies. Unknown dates are not inferred. Source spans identify original text-part index and end-exclusive UTF-16 offsets, reject surrogate splitting, and retain a digest rather than raw source text. The server assigns an origin root per scene/message; source edits are revisions of the same root, not independent corroboration. A valid substring proves position, not that the model understood quotation, stance, or truth.

Only the fixed low-risk admission policy can mark a qualified claim accepted. Self attribution requires a real cited self witness. Direct general assertions use a distinct asserted stance. Reported/quoted support cannot become explicit self facts; such edges remain qualified candidates. Accepted means index admission, never externally verified truth or permission to act. No graph predicate authorizes messages, tools, or access to another scene.

## Actual reads and learning

`memory.knowledge` reads a bounded whole-page receipt. A person anchor remains scene-scoped. An entity anchor must have been delivered in an earlier complete graph receipt in the same turn. A memory anchor starts from the exact first-delivered ordinary memory body/version/epoch; it never upgrades a supplied ID to the latest revision. The admin query is separately authenticated and checks exact backing material; it is not a model exposure ticket.

One- and two-hop paths are discovery paths, not transitive factual conclusions. Negative, possible, conditional and conflicting claims remain in their conflict group. Queries scan at most 201 rows to detect the 200-row scene limit, share a 512-work proof traversal budget, and bound roots, edges and paths. Exceeding a bound returns explicit limited coverage without a misleading positive prefix. These limits are not a claim that an arbitrary large graph has been fully searched.

Whole-page budget omission grants no entity authority. Actual delivery is revalidated synchronously, and later usage repeats scope, source, backing, qualifier and policy checks. Graph-derived free-form memory, habit, and strategy proposals are refused. Typed contextual declarations use an internal fixed marker instead of model-expanded graph prose or raw chat. Their full structured terms live only in the dependency-protected graph. Every previously delivered graph edge and ordinary assertion used by that contextual turn is bound through server-owned inherited read dependencies, not a model-selected subset. Each dependency retains its original complete proof alternatives; all inherited dependencies must remain available. The query carries a bounded, flat, de-duplicated supporting-edge and exact-backing-record closure in the same evidence page, so conditions in a premise are not replaced by bare references. Markers are excluded from ordinary memory/person/vector retrieval but remain visible to authenticated diagnostics. Fresh independent source-only learning remains available. This graph uses scene-backed authority; a contextual turn that also depends on shared-public or unavailable backing material is conservatively rejected rather than granting cross-scene graph authority.

Personalization OFF still permits general fact/claim/term knowledge with no personal backing. If a graph page includes personal endpoints or personal backing material, the whole page is refused rather than deleting a counterexample and presenting the remainder as complete. Read OFF stops model graph reads; authenticated management remains available.

## Revocation, recovery and limits

Source recall removes affected complete proof groups and spans, preserves independently authorized OR alternatives, and clears reverse typed dependencies when their origin is lost. Surviving same-semantics evidence may be requalified only across the exact authorized pre-recall→committed post-recall reference map; ordinary edits, metadata drift, or unrelated recalls cannot rebind stale evidence. Terminal assertion deletion removes its graph material. Current source edits make stale evidence unavailable without being treated as privacy deletion.

Reader version 7 recognizes the strict graph schema. Configuration revision v6 includes the three controls. Old-backup recovery replays the covered safety operations against material actually present; it does not recreate later learning, missing graph bodies, or semantic decisions. Unsupported schema, malformed records or unavailable required material fail closed. Knowledge admission itself is derived from existing assertion authority, not a new independent administrative grant.

Offline synthetic tests establish mechanism, isolation, bounded closure and revocation behavior. Real extraction accuracy, usefulness, and model retention of qualifiers still require separately authorized provider evaluation. This slice does not implement unconstrained relation induction, arbitrary unit conversion, entity co-reference inference, or a universal knowledge graph.
